# Frontend usability guard

When changing frontend behavior, controls, layout or visible feedback, read and use
[`ui-ux-audit`](../.agents/skills/ui-ux-audit/SKILL.md). Review the affected flow
proportionately and report concrete findings/fixes so the user can steer.

Prioritize normal usability, truthful audio state, preserved edits and recovery.
Preserve existing accessibility tests; do not expand work into a compliance audit
unless requested. Backend-only, documentation-only and test-only maintenance do
not require a full UI review. Root AGENTS.md remains authoritative for delivery.
