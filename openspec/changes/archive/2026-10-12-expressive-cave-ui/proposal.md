# Expressive cave interface

## Why

The first branding pass is too restrained for the requested caveman identity. The user requests a more expressive, polished purple/lime interface and clearer disclosure of input clip adjustments in the current branding PR.

## What Changes

- Give the header, workflow navigation, panels, audio transport and selection states a coherent carved stone/cave/rhythm identity with roughly 75% purple/pink and 25% pale lime accents.
- Keep readable accessible light/dark themes and the existing three workflows.
- Rename the closed input-audio sample settings disclosure to Clip adjustments, explain its effect and keep it inside the Input Audio widget. Its settings apply to all source clips, so it remains available for all clips.
- Refresh README accuracy and provide explicit before/after screenshots in the PR.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `theme-system`: more expressive cave artwork and deliberate purple/lime balance.
- `frontend-service`: clearly named, nested clip adjustment disclosure.

## Impact

Frontend styling/markup, screenshot evidence and maintained documentation. No new runtime dependency or changed audio processing, model, installer or recipe contracts.
